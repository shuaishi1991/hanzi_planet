# 识字启蒙 · 使用说明

## 打开方式
双击 `index.html` 即可在浏览器中打开，无需联网、无需安装。

**请拷贝整个文件夹**（含 `css/`、`js/`、`audio/`），不要只拷单个 html。

可选：本目录运行 `sh start.sh`，浏览器访问 http://localhost:8000（麦克风权限更稳）。

## 目录结构
- `index.html` — 页面入口
- `css/app.css` — 样式与内嵌楷体
- `js/pinyin.js` — 朗读判读用拼音表
- `js/books.js` — 三册课程数据（加第二、三册只改这里）
- `js/app.js` — 程序逻辑
- `audio/` — 预生成朗读音频（晓晓音色）
- `tools/generate_audio.py` — 音频生成脚本（新增课文后运行）
- `samples/` — 音色试听样例（可删）

## 内容
- **第一册**：已按原书录入全部 22 课（每课 = 生字带拼音 + 词语 + 句子；长句按「不超过约 10 字」在标点处拆分，**保留原标点**）
- **第二、三册**：待拍照录入，程序中显示「内容筹备中」
- 「读一读」句子：按原句顺序；同一原句的短片段横向连排（可自然折行），**不同原句之间换段并用灰线分隔**；字、词仍随机

## 发音说明
- 优先播放 `audio/` 下预生成的 **晓晓（Xiaoxiao）** 神经语音；找不到对应文件时回退到系统 TTS
- 新增课文后，在本机联网执行：
  ```bash
  pip install edge-tts
  python3 tools/generate_audio.py
  ```
  只会补生成缺失的条目。

## iPad 使用建议（推荐横屏）
- 程序已适配横屏：iPad mini 横置时自动切换为左右双栏布局，一屏显示全部内容，无需滚动
- 竖屏也可正常使用（自动变回单列布局）
- 建议在 iPad Safari 中打开后，点「分享 → 添加到主屏幕」，之后从主屏幕图标启动即全屏无浏览器边框，更像一个 App
- iPad 上「读一读」系统判读可用（走苹果语音服务，国内正常）；如识别不了，请在 设置 → Siri 中开启 Siri 和听写，或在程序内切换为家长评判

## 每课三步
1. 🎴 **认一认**：大字卡 + 拼音，点字听发音，每个字下面挂最常用词语（点词语也能听）
2. 🎧 **听音选选**：大喇叭自动播音（点击可重播），从 4 张选项大卡中选出正确的汉字/词语——本课全部生字和词语各出一遍，不落一个
3. 🎤 **读一读**：看汉字/词语/句子大声朗读——按「一页 8 个字 / 6 个词 / 3 个句子」分页展示本课全部内容，黄框高亮当前要读的；底部固定控制栏（麦克风/评判/重试都在栏内切换，页面不跳动）；「🔊 听示范」可随时听标准发音

所有课程随时可学（无顺序锁定）。三步都完成 → 本课得星 ⭐。进度自动保存在浏览器本地。

## 多设备同步进度（💾 存档码）
- 进度（金币/课程完成/错题本）默认只存在**当前这台设备的这个浏览器**里
- 首页点「💾 存档」→「📋 复制存档码」，把这段码发到微信/备忘录
- 在另一台设备（手机/电脑/iPad 均可）打开本页面 →「💾 存档」→「📥 导入」粘贴存档码 → 进度完整迁移
- 注意：导入会**覆盖**目标设备上的现有进度

## 日常任务 ✨
- 首页点「✨ 任务」：完成识字以外的作业也能领金币
- 默认任务：写一页字帖（🪙 50）、完成一页数学练习（🪙 20）
- 可自定义任务名称与金币数，也可修改 / 删除
- 领取前请家长确认已完成

## 金币明细 🪙
- 点任意页右上角 **金币余额** 进入：查看全部增加 / 消耗记录
- 汇总显示当前余额、累计获得、累计消耗、已兑现金

## 金币兑奖 💵
- 首页点「💵 兑奖」：按 **🪙 50 = ¥1** 兑换真实现金面额
- 可选面额：¥1 / ¥5 / ¥10 / ¥20 / ¥50 / ¥100（均可重复兑换）
- 对应消耗：50 / 250 / 500 / 1000 / 2500 / 5000 金币
- 程序只记账并扣减金币；**真钱由家长兑现**给孩子存起来
- 兑奖页只显示汇总；详细流水在「金币明细」里查看

## 错题本 📒
- 答错/读错的字、词、句自动进入错题本（首页左上角进入）
- 点任意条目可听发音
- 「开始攻克错题」：错题按听音选/朗读混合出题，同一题连对 2 次即「攻克」并移出错题本

## 朗读判读的浏览器要求（重要）
「读一读」的系统自动判读依赖浏览器语音识别：

| 浏览器 | 系统判读 | 说明 |
|---|---|---|
| **Edge（推荐）** | ✅ 国内可用 | 识别走微软服务器，国内网络正常 |
| Safari（Mac/iPhone/iPad） | ✅ 可用 | 需开启 Siri/听写 |
| Chrome | ⚠️ 国内不可用 | 识别走谷歌服务器，被墙 |

系统判读不可用时，程序会**自动切换为「家长评判」**（家长听孩子读，点 ✓/✗），也可以随时手动切换。

## 朗读判读需要麦克风权限
- 首次点麦克风时浏览器会弹权限请求，请选择「允许」
- 如果双击打开时麦克风不可用，可在本目录运行 `sh start.sh`，然后浏览器访问 http://localhost:8000

## 录入其余内容
把**第二、三册**的目录页 + 每课字表/词语/句子整理进 `js/books.js`（格式同第一册），再运行 `python3 tools/generate_audio.py` 补音频即可。
