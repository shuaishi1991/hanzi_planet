# 识字启蒙 · 使用说明

纯前端离线网页：认字、听音选、朗读练习，配金币任务与错题本。无需安装、无需后端。

## 打开方式

双击 `index.html` 即可在浏览器中打开。

**请拷贝整个文件夹**（至少含 `css/`、`js/`、`audio/`），不要只拷单个 html。

可选：本目录运行 `sh start.sh`，浏览器访问 http://localhost:8000（麦克风权限更稳）。

也可用 GitHub Pages 等静态托管发布；进度仍保存在各浏览器本地，换设备请用「存档码」。

## 目录结构

- `index.html` — 页面入口
- `css/app.css` — 样式与内嵌楷体（BookKai；「角」用系统楷体）
- `js/pinyin.js` — 朗读判读用拼音表
- `js/books.js` — 三册课程数据（改课文只改这里）
- `js/app.js` — 程序逻辑
- `audio/` — 预生成朗读音频（晓晓音色）
- `tools/generate_audio.py` — 音频生成脚本（新增课文后运行）
- `start.sh` — 本地静态服务
- `samples/` — 音色试听样例（可删）
- `ori_pics/` — 原书拍照参考（非运行必需，体积大，发布时可省略）

## 内容

| 册 | 课数 | 说明 |
|---|---|---|
| **第一册** | 22 课 | 生字（带拼音）+ 词语 + 句子 |
| **第二册** | 22 课 | 同上 |
| **第三册** | 51 课 | 同上；每课有文章标题（如「拔萝卜」） |

### 句子录入规则

- **第一、二册**：长句按「不超过约 10 字」在标点/词界处拆成片段，**保留原标点**；读一读时同一原句的片段横排连读，不同原句之间换段并用灰线分隔。
- **第三册**：每个自然段为一组（不做 10 字拆分）；读一读句子段开头先读**文章标题**，再读正文各段。

字、词在「读一读」中仍随机顺序；句子按课文顺序。

## 发音说明

- 优先播放 `audio/` 下预生成的 **晓晓（Xiaoxiao）** 神经语音；找不到对应文件时回退到系统 TTS。
- 短文本用中文文件名；过长段落用 `h_<SHA-256前16位>.mp3`（生成脚本与网页规则一致）。
- 新增或改课文后，在本机联网执行：

  ```bash
  pip install edge-tts
  python3 tools/generate_audio.py
  ```

  只会补生成缺失的条目。可用 `--concurrency 8` 加速。

## 每课三步

1. 🎴 **认一认**：大字卡 + 拼音，点字听发音；每个字下面挂常用词语（点词语也能听）。
2. 🎧 **听音选选**：大喇叭自动播音（点击可重播），从 4 张选项卡中选出正确汉字/词语——本课全部生字和词语各出一遍。
3. 🎤 **读一读**：看汉字/词语/句子大声朗读。
   - 字约 8 个/页、词约 6 个/页；**句子按可视高度动态分页**（尽量沾满一屏且不顶出判定区）。
   - 黄框高亮当前要读的项；底部固定麦克风 / 家长 ✓✗ 评判。
   - **每个判定单元末尾有 🔊**，可随时点听该条示范音；也可用「听当前」。

三步都可随时进入（无顺序锁定）。全部完成 → 本课得星 ⭐。切换认/听/读标签会保留本课已进入过的进度；存档/导入也会带上当前练习进度。

## iPad 使用建议（推荐横屏）

- 已适配横屏：iPad mini 横置时自动切换布局，尽量一屏显示。
- 竖屏也可正常使用。
- 建议 Safari →「分享 → 添加到主屏幕」，全屏更像 App。
- 「读一读」系统判读走苹果语音服务；不可用时请开 Siri/听写，或改用家长评判。

## 多设备同步进度（💾 存档码）

- 进度（金币 / 课程完成 / 错题本 / 练习进度）默认只存在**当前设备的这个浏览器**里。
- 首页「💾 存档」→「📋 复制存档码」，发到微信/备忘录。
- 另一台设备打开本页 →「💾 存档」→「📥 导入」粘贴 → 完整迁移。
- 导入会**覆盖**目标设备上的现有进度。

## 金币奖励 🪙

- 答题/朗读正确：+2 金币（首次答对）
- 每个环节首次完成：+5~10 金币
- 整课三环节全完成：+20 金币
- 金币每满 100 触发庆祝 🏆，余额在页面右上角

## 日常任务 ✨

- 首页「✨ 任务」：完成识字以外的作业也能领金币
- 默认：写一页字帖（🪙 50）、完成一页数学练习（🪙 20）
- 可自定义名称与金币数，可修改 / 删除
- 领取前请家长确认已完成

## 金币明细 🪙

- 点右上角 **金币余额**：查看全部增加 / 消耗记录
- 汇总：当前余额、累计获得、累计消耗、已兑现金

## 金币兑奖 💵

- 首页「💵 兑奖」：按 **🪙 50 = ¥1** 兑换面额
- 可选：¥1 / ¥5 / ¥10 / ¥20 / ¥50 / ¥100（可重复）
- 对应消耗：50 / 250 / 500 / 1000 / 2500 / 5000 金币
- 程序只记账扣币；**真钱由家长兑现**
- 兑奖页只显示汇总；明细在「金币明细」

## 错题本 📒

- 答错/读错的字、词、句自动进入错题本（首页进入）
- 点条目可听发音
- 「开始攻克错题」：听音选 / 朗读混合出题，同一题连对 2 次即攻克并移出

## 朗读判读的浏览器要求（重要）

「读一读」的系统自动判读依赖浏览器语音识别：

| 浏览器 | 系统判读 | 说明 |
|---|---|---|
| **Edge（推荐）** | ✅ 国内可用 | 识别走微软服务器 |
| Safari（Mac/iPhone/iPad） | ✅ 可用 | 需开启 Siri/听写 |
| Chrome | ⚠️ 国内常不可用 | 识别走谷歌服务器 |

不可用时会**自动切到「家长评判」**（家长听孩子读，点 ✓/✗），也可手动切换。

## 麦克风权限

- 首次点麦克风时请允许权限。
- 若双击 `file://` 打不开麦克风，请用 `sh start.sh` 经 http://localhost:8000 访问，或使用 HTTPS 静态托管。

## 维护课文

1. 编辑 `js/books.js`（结构同现有课；第三册可加 `articleTitle` 作为读一读首句）。
2. 运行 `python3 tools/generate_audio.py` 补音频。
3. 对照原文可用 `ori_pics/`（可选保留）。
